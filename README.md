# 🎫 Sistema de Tickets de Suporte

Uma plataforma web para gerenciamento de solicitações de suporte técnico, desenvolvida para centralizar o atendimento, organizar chamados e facilitar a comunicação entre usuários e equipes de suporte.

O sistema permite acompanhar o ciclo de vida dos tickets, desde a abertura até a resolução, com controle de prioridades, status e interações em tempo real.

## ✨ Funcionalidades

- **Gerenciamento de tickets:** abertura, visualização, edição e acompanhamento de solicitações.
- **Controle de status:** organização dos chamados durante as etapas de atendimento.
- **Prioridades:** classificação dos tickets de acordo com o nível de urgência.
- **Comunicação em tempo real:** atualização das interações utilizando WebSockets.
- **Autenticação e autorização:** controle de acesso conforme o perfil do usuário.
- **Comentários e interações:** comunicação entre solicitantes e responsáveis pelo atendimento.
- **Filtros e pesquisa:** localização de chamados por diferentes critérios.
- **Interface responsiva:** experiência adaptada a diferentes tamanhos de tela.

## 🧪 Testes

O frontend conta com ferramentas para validação e testes, buscando garantir maior confiabilidade e qualidade da aplicação.

- **Vitest:** execução de testes automatizados.
- **Testing Library:** testes de componentes e interações da interface.
- **Playwright:** testes end-to-end para validar fluxos completos da aplicação.

## 🔌 Backend

A aplicação utiliza uma API REST independente, responsável pelas regras de negócio, autenticação, gerenciamento dos chamados e comunicação com o banco de dados.

## 🎯 Objetivo do projeto

O projeto foi desenvolvido com o objetivo de aplicar conceitos de desenvolvimento frontend moderno, integração com APIs, gerenciamento de estado, autenticação, comunicação em tempo real e testes automatizados.

Além da construção da interface, o desenvolvimento busca colocar em prática boas práticas de organização de código, componentização, validação de formulários e criação de uma experiência consistente para os usuários.
